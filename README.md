# PharmCare OPD

ระบบบันทึกการบริบาลทางเภสัชกรรมผู้ป่วยนอก กลุ่มงานเภสัชกรรม โรงพยาบาลอุตรดิตถ์

- ใช้บัญชีเดียวกับ PharmShift เข้าได้เฉพาะเภสัชกร (`pharmacist`) และผู้ดูแลระบบ (`admin`)
- กรอก HN แล้วดึงชื่อและคลินิกจาก HIS ผ่านตัวกลางในโรงพยาบาล จากนั้นเลือกประเภทการบริบาล
- งานที่ครอบคลุม: ติดตามโรคเรื้อรัง, ปัญหาจากการใช้ยา (DRP), ยาความเสี่ยงสูง, ADR / แพ้ยา, สอนเทคนิคการใช้ยา
- ลบรายการไม่ได้ ทำได้แค่ยกเลิกพร้อมเหตุผล ทุกการเปลี่ยนแปลงเก็บใน audit log ที่ระดับฐานข้อมูล

## โครงสร้าง

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `/` | เว็บแอป Next.js |
| `relay/` | `his-relay` ตัวกลางในเครือข่ายโรงพยาบาล ค้นข้อมูลผู้ป่วยจาก HN |
| `docs/` | ความคืบหน้า และดีไซน์หน้าจอ (`docs/design/`) |

## ความปลอดภัยของข้อมูล

ห้าม commit ข้อมูลผู้ป่วยจริง, ไฟล์ `.env`, ไฟล์ export หรือ dump ฐานข้อมูล ข้อมูลตัวอย่างใช้ข้อมูลสมมติเท่านั้น

ความคืบหน้า: [docs/PROGRESS.md](docs/PROGRESS.md)
